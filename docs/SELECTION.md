# 收录标准与来源边界

## 来源与时间

依据私有来源目录 `1998x-stack/1998x-stack-catalog` 所维护、观察日为 **2026-11-03** 的 709 项仓库历史快照，从其中的 **578 个标记为 public** 的仓库筛选。**只输出 35 个明确公开、与游戏直接相关或在游戏研究中有明确用途的链接和简短描述**；没有把整个来源数据镜像到此公开仓库。当前链接可用性可能随时间变化；需要定期复核。

## 分类规则

每个仓库仅分配一个主要类别。游戏作品优先按玩法分类；以训练或搜索为主的项目归入游戏 AI；环境、接口或 benchmark 归入游戏环境；生成游戏的软件归入创作工具；以教学为主的归入教程。

## 保守与例外

- `gym`、`RL-Adventure-2` 和部分教程为**游戏研究相关的通用工具**，并不保证本身是可玩的游戏。它们已被明确标入研究/环境分类。
- `Snake_Web`、`math_game`、`MarioGame`、`xiao_xiao_le_game`、`gomoku_zero` 等缺少在本次整理中充分核对的说明，采用保守描述并标记“待进一步复核”。
- `social_town` 是社会动力模拟，不是以游戏为主；`supermariopy` 是通用数据工具，并非马里奥游戏；二者不纳入。
- 不收录纯通用 AI/RL 训练框架、机器人 RL、编译器、网页工具，避免因名字中的“engine/rl/game”关键词而误选。
- 本索引不意味着上游通过安全审计、内容审核、维护活跃或获得公共部署许可。原项目版权及许可由其各自所有者决定。

## 维护流程

1. 对新增项目先核实 GitHub visibility 为 public，再审查 README 或实际代码，按主要功能归类。
2. 更新 `data/games.json`、类别 README 和项目占位 README。
3. 执行 `python3 scripts/build_site.py --check`，检查链接前缀、唯一性、分类数量、目录对应与数据一致性。
4. 将变更经 PR 审核后合并。不得从私有来源直接复制全量清单、内部审查报告或凭据。
